## Summary

Drop per-generation telemetry from the `discovery` and `discovery_at_scale` examples and replace it
with a single milestone-summary SVG sourced from `evolveDir`'s return value via the shared
`common/evolve_dir_summary.ts` helper from #284. Closes #304.

For each example:

- The `onTrainingEvent` hook, chunked `evolveDir` loop, and per-generation row helpers
  (`EvolutionRow`, `formatEvolutionCsv`, `rowsToFitnessSamples`, `rowsToEvolutionSamples`) are
  removed.
- The runner captures `{ error, score, time, generation }` from a single `evolveDir` call plus the
  pre/post topology counts, builds an `EvolveDirSummary`, and renders it to
  `docs/screenshots/<example>/evolution_summary.svg` via `renderEvolveDirSummarySvg`.
- The deprecated `EVOLUTION_CSV_*`, `FITNESS_SVG_PATH`, and `TOPOLOGY_SVG_PATH` constants and their
  imports from the per-generation chart helpers are gone.
- The legacy headline at `docs/screenshots/discovery_at_scale.svg` is re-sourced as a mirror of the
  new milestone summary so the seed-vs-final topology bars become the demo's headline visual.
- The root README's "Unique Features Showcase" row for `discovery_at_scale` now points at the
  milestone summary and describes the seed-vs-final topology delta instead of the per-generation
  curves.
- Deprecated artefacts under `docs/data/<example>/evolution.csv`,
  `docs/screenshots/<example>/fitness.svg`, and `docs/screenshots/<example>/topology.svg` are
  deleted.

## Evidence

This is a CLI / artefact change; there is no web UI to screenshot. The new milestone summary SVGs
were generated by running the examples end-to-end:

- `./discovery/run.sh` → wrote `docs/screenshots/discovery/evolution_summary.svg` (903 generations,
  finalError 0.0003, 5/4 → 7/15).
- `./discovery_at_scale/run.sh` → wrote `docs/screenshots/discovery_at_scale/evolution_summary.svg`
  and mirrored it to `docs/screenshots/discovery_at_scale.svg` (603 generations, finalError 0.0768,
  9/18 → 18/48).
